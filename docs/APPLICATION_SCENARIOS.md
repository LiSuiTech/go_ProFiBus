# go_ProFiBus 应用场景手册

## 概述

go_ProFiBus 是一个功能强大的工业数据采集、分析和控制平台，集成了多协议数据采集、AI异常检测、多数据源融合和自动设备控制等功能。

本文档详细介绍了该系统在不同行业和场景下的应用方案。

## 制造业场景

### 1.1 数控机床监控与保护

**业务需求：**
- 实时监控机床温度、振动、电流
- 检测刀具磨损、主轴异常
- 自动暂停/紧急停止保护设备

**技术方案：**

```
[传感器网络]
  ├─ 温度传感器 (MQTT/OPC-UA)
  ├─ 振动传感器 (MQTT)
  ├─ 电流传感器 (Modbus)
  └─ 压力传感器 (OPC-UA)
        ↓
  [数据融合引擎]
    - 加权融合策略
    - 卡尔曼滤波去噪
        ↓
  [AI异常检测]
    - 神经网络模型
    - 特征工程
        ↓
  [控制策略]
    - 温度>80°C → 降速运行
    - 振动>5g → 暂停检查
    - AI异常分数>0.9 → 紧急停止
        ↓
  [执行器]
    - OPC-UA调用PLC方法
    - MQTT发送控制命令
```

**控制规则示例：**

```go
// 刀具磨损检测
wearRule := &interfaces.ControlRule{
    ID: "tool_wear_detection",
    Name: "刀具磨损保护",
    Priority: 85,
    Condition: interfaces.RuleCondition{
        AnalysisType: "ml_anomaly_detection",
        MinScore: 0.75,
        CustomEvaluator: func(result interfaces.AnalysisResult) bool {
            vibration, _ := result.Details["vibration"].(float64)
            current, _ := result.Details["current"].(float64)
            // 振动和电流同时异常表明刀具磨损
            return vibration > 4.0 && current > 60.0
        },
    },
    Actions: []*interfaces.ControlAction{
        {
            ActionType: interfaces.ActionPause,
            TargetDevice: "cnc-machine-01",
            Reason: "检测到刀具可能磨损",
            RequireConfirmation: true,
        },
    },
    Cooldown: 10 * time.Minute,
}
```

### 1.2 注塑机智能优化

**业务需求：**
- 监控注塑压力、温度、周期时间

- 预测设备故障

- 缺料检测 → 暂停产线

## 通用功能特性

### 多协议支持

所有场景都可使用以下协议组合：

| 协议 | 适用设备 | 特点 |
|------|---------|------|
| **MQTT** | IoT传感器、轻量级设备 | 低功耗、高并发 |
| **OPC-UA** | PLC、SCADA系统 | 工业标准、安全性高 |
| **Modbus** | 传统工业设备 | 简单可靠、广泛支持 |
| **HTTP/REST** | Web系统、云平台 | 易集成、跨平台 |
| **串口** | 老旧设备、嵌入式系统 | 兼容性好 |

### AI异常检测

支持多种AI模型：

- **神经网络**: 复杂模式识别
- **SVM**: 二分类异常检测
- **决策树**: 规则提取
- **时序分析**: 趋势预测

### 控制策略

灵活的控制规则引擎：

```go
// 示例：组合条件
rule := &interfaces.ControlRule{
    Condition: interfaces.RuleCondition{
        CustomEvaluator: func(result interfaces.AnalysisResult) bool {
            temp, _ := result.Details["temperature"].(float64)
            vib, _ := result.Details["vibration"].(float64)
            score := result.Score

            // 温度高 且 振动大 且 AI分数高 → 触发
            return temp > 85 && vib > 5.0 && score > 0.85
        },
    },
    Actions: []*interfaces.ControlAction{
        {ActionType: interfaces.ActionEmergencyStop},
    },
}
```

### 权限管理

细粒度的控制权限：

- 按动作类型授权
- 按设备授权
- 按严重程度授权
- 按时间段授权
- 是否需要人工确认

## 总结

go_ProFiBus 平台通过以下核心能力，支持上述所有场景：

1. **多协议数据采集**: MQTT、OPC-UA、Modbus等
2. **数据融合**: 10种融合策略，处理多源异构数据
3. **AI异常检测**: 神经网络、SVM等多种模型
4. **自动设备控制**: 基于规则的智能控制
5. **权限管理**: 细粒度的安全控制
6. **灵活扩展**: 插件化架构，易于定制

无论是工业制造、能源管理、智慧建筑还是环境监测，该平台都能提供完整的解决方案。
